# Portfolio audit 001

Reviewed the finished English portfolio in Anti Slop after mode on 9 November 2026. The owner requested revisions to the visual clichés, repeated components, generic copy and lack of project context identified below.

## Findings before revision

| No. | Priority | Rule | Observation and proposed edit |
| --- | --- | --- | --- |
| 1 | Medium | R-22, R-19 | A swinging monogram, imitation barcode and shaded ring take the largest visual slot. Use that space to show which days the rupiah model flagged, using the dates in the study. |
| 2 | Medium | R-09, R-06 | Numbered labels introduce sections whose headings then say something else. Put Rayyan's name in the main heading, name each section directly and use monospaced type for measurements. |
| 3 | Medium | R-14 | Four equal project cards give a square scatterplot, a wide residual chart and a catalogue screenshot the same frame. Give the scatterplot a full-size lead and the other studies illustrated rows. |
| 4 | Low | R-05 | A row of three counters repeats the tab totals. The tools panel also uses nine large cards for nine short entries. Keep counts at the tabs and organize the tools by use. |
| 5 | Low | R-16, R-20 | “Data, with perspective”, “Curiosity first. Evidence always.” and the closing invitation could belong to any portfolio. Use the supplied biography, actual methods and documented results. |
| 6 | Low | R-15 | All projects use “Read project”. LinkedIn appears twice inside Contact. Name the action for each study and give each profile one clear listing in Contact. |

The site already uses the locally supplied type families, actual project images, original certificates and a single blue interface accent. The review found no stock portraits or neon color gradient to replace.

## Direction for the revision

A statistics portfolio for someone deciding whether to read Rayyan's work. Keep the dark split opening, straightforward navigation and manual certificate viewer. Give the dither pattern a statistical meaning, with one mark per daily observation. Use a large name, plain-language biography and full project evidence. **Energy 3 / rhythm 3 / motion 1.**
